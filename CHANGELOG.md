# Changelog

## 0.1.0 — initial public preview

- Local clipboard history for macOS and Linux: text, rich text, images,
  files, pins, preview and search.
- Local screenshot OCR, paste stacks, optional copy sounds and macOS
  hold-to-cycle. English, French and Spanish.
- Capture-safe recovery for unreadable settings, secret-type exclusions,
  user-only storage permissions, bounded image decoding and OCR storage.
- CI for tests, race detection, secrets, reachable Go vulnerabilities and
  cross-platform installers. Tagged releases include checksums, build
  provenance and bundled third-party notices.

This is a preview, not a stable release. macOS packages are ad-hoc signed
and not notarized. Real Mac permissions/paste/OCR/audio and native Wayland
desktop behavior still need hands-on validation; Linux ARM64 is cross-built.
