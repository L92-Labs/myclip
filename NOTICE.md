# NOTICE

MyClip is an independent, clean-room Go implementation of a clipboard manager
for macOS. Its feature set targets parity with [Maccy](https://github.com/p0deje/Maccy)
by Aleksey Rodionov, released under the MIT License. MyClip does not contain
Maccy source code; Maccy's documentation and behavior were used as a
specification reference. All credit for the original design belongs to the
Maccy authors.
