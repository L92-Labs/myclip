# MyClip — Implementation Plan (v8)

Lightweight, open-source, 100%-local clipboard manager for macOS. **Parity contract: Maccy 2.7.1 @ `eb03eba` — `PARITY.md` is the authoritative inventory.** Stack: Go + [MyGo](https://mygo.egoist.dev) v0.5.5 (pure Go, no cgo, native GPU UI, tray, global shortcuts, clipboard APIs, SQLite plugin, updater).

Repo: `L92-Labs/myclip` (private now; public later). MIT + `NOTICE.md` (Maccy notice reproduced verbatim @ 2.7.1). Bundle ID `com.l92labs.myclip` (locked; TCC keys off code-signing identity ⇒ stable signing identity required from M1). Go module `github.com/L92-Labs/myclip`.

## Non-negotiable constraints

- N1: No cloud, no telemetry, no unsolicited network — production included. SQLite: MyGo gates its native-lib download behind a runtime `IsPackaged()` check (NOT compile-time); ⇒ N1 evidence (nettop zero-outbound) runs on a **packaged `.app`** from `mygo build` (library bundled), never on dev builds; system `libsqlite3.dylib` is NOT a fallback (missing MyGo shim symbols); `MYGO_SQLITE_LIBRARY` is honored at runtime even in packaged builds (env checked before bundle lookup) ⇒ on `App.IsPackaged()` MyClip calls `os.Unsetenv("MYGO_SQLITE_LIBRARY")` before any sqlite load; M1 test: packaged app launched with the env set resolves its library under `Contents/Resources` only. Updater: constructed only as `updater.New(Options{DisableAutomaticChecks: true, …})`; bare `updater.Plugin` forbidden (grep); on every launch MyClip applies its own stored preference — `myclipPref` lives ONLY in MyClip's settings store (default false), never read from `updater.json`: `SetAutomaticChecks(myclipPref)` before `WhenReady` (the plugin's update-window checkbox may write `AutomaticDownloads`). MyGo surface known from source: getter `AutomaticChecks()`, state file `<PathUserData>/updater.json`, `automaticChecks *bool` nil ⇒ `!DisableAutomaticChecks`. M1 test: pre-seed `updater.json` with `{"automaticChecks":true}` → launch packaged app → assert `AutomaticChecks()==false` (pref default; proves plugin state does not leak into pref); then opt in from the app, relaunch, assert `true`; nettop zero egress past `firstCheckWait` (10 s) + idle when off.
- N2: Behavioral parity with Maccy 2.7.1 per `PARITY.md`; every row maps to a milestone or an approved deviation (D1–D11 in PARITY §6; new deviations require user sign-off before implementation). Gaps found later = findings; never silent drops.
- N3: Open source (MIT); Maccy notice verbatim; THIRD_PARTY_NOTICES generated at M5.
- N4: Measurable per milestone evidence gate: binary size, idle RSS, idle CPU% over ≥5 min — "no busy-wait; envelope comparable to Maccy side-by-side in Activity Monitor."
- N5: Review gates per `feature-review-loop` skill; every gate reviewer gets a full fresh-defect pass on the final revision (gate minimums are never reduced by routing). User routing preference: Cursor Agent Auto does the heavy/deep passes; Claude/ChatGPT at skill minimum. cgo is a hard non-goal; any capability impossible via purego becomes an explicit plan decision, never silent.
- N6: Security: ignore test = **any** banned/concealed/transient UTI present in the **full raw pasteboard type set** ⇒ ignore before any data read (never strip-then-check). Secrets never enter the DB.

## Architecture

1. **Purego darwin shim layer** (`internal/darwin`): `changeCount`; raw UTI enumeration (`NSPasteboard.types`, incl. MIME-less types); `frontmostApplication` bundle ID; keycode-from-layout (TIS/UCKeyTranslate; QWERTY force when layout name ends `⌘`); CGEvent posting; tray `NSEvent.modifierFlags` probe inside `OnClick` (spike; fallback = menu items, then PARITY row demotion = deviation). Pasteboard access behind an interface with a read-counting fake for Linux tests + named-`NSPasteboard` darwin test (N6 test seam).
2. **Item model**: one history item, N representations (raw UTI + bytes), source bundle ID, firstCopiedAt/lastCopiedAt, numberOfCopies, pin, title override. Dedup/equality per Maccy's supersede rule — exact excluded/transient-type list ported from `HistoryItem` @ `eb03eba` as an M1 pre-task (asserted in PARITY §1, not summarized). **Own-write handling: NOT skipped — full `History.add` merge matrix: match by representation set ⇒ update lastCopiedAt + numberOfCopies + position; preserve firstCopiedAt, pin, title; application/source rules per Maccy's `.fromMaccy` path.** Marker UTI `com.l92labs.myclip.own-write` is **metadata only**: checked for origin, never stored as a representation, never written back to other apps, excluded from the equality set (occupies the `.fromMaccy` slot in the ported excluded-types list). M1 tests: copy-back bumps count; pinned stays pinned; no dup row; firstCopiedAt and title-override preserved; no marker rep in DB after copy-back; equality excludes marker.
3. **Capture pipeline (Maccy-ported rules, each with M1 test)**: early-exit **only** on `ignoreEvents` (on that exit, if `ignoreOnlyNextEvent` is set, both flags are cleared — skip-exactly-one semantics). Tray coupling: **M1 pre-task quotes the exact `performStatusItemClick` body @ `eb03eba` into PARITY §1** (the ⌥/⌥⇧ flag assignments must be ported verbatim — as-written approximations are forbidden; the `ignore-next` CLI verb (D5) sets both flags with the same effect as the tray path). M1 tests: pause-sticky, from-unpaused ⌥⇧click → next copy skipped → the copy after it captured, no OR-false-positive. Ignore chain on the **full raw type set**: ignore if disjoint from `enabledPasteboardTypes`, or if ANY intersection with (always-ignore trio ∪ user's `ignoredPasteboardTypes`); `com.apple.is-remote-clipboard` enters the set **only via user setting** (not in Maccy's default) — default builds must capture Universal Clipboard copies. Then source app (ignoredApps / allowlist) → regex on text. Content rules: merge multiple `pasteboardItems` into one record; skip empty `string` unless RTF/HTML present; strip `dyn.*` and `com.microsoft.ole.source.*`; drop Word ObjectLink/Link-Source sets. **PasteStack/multi-select: not ported — disabled dead code in 2.7.1** (`AppState.multiSelectionEnabled = false` ⇒ `startPasteStack` guard unreachable; rejected with evidence in LEDGER; revisit if upstream enables it).
4. **Storage**: SQLite. File pre-created `O_CREAT|O_EXCL` mode 0600 in 0700 dir **before** `sqlite.Open` (MyGo creates 0644 by default); on pre-existing file (`EEXIST`, e.g. earlier dev build): `fstat` + `fchmod` to 0600 (dir 0700) or refuse startup; sidecar (`-journal`/`-wal`/`-shm`) modes asserted in M1 test. **Journal mode pinned** (`DELETE`, or WAL + `wal_checkpoint(TRUNCATE)` + `VACUUM` on clear-all); secure_delete pragma per-connection; forensics test greps DB dir (sidecars incl.) for sentinel after clear. Size caps + total budget = **deviation D6** (user sign-off; D1/D5/D6 block M1 until approved). Enabled-types default set verified against `Defaults.Keys+Names.swift` as M1 pre-task.
5. **App shell**: accessory app, no Dock icon. **Non-activating popup spike moved to M1** (key window without app activation, text input works, Esc + focus-loss close) — paste-back spike runs from that real window type, so the M1 focus model is validated on the final surface.
6. **Paste-back**: CGEvent-only (no osascript — avoids a second Automation TCC prompt). Sequence: hide popup → bounded activate/wait on captured (pre-popup) frontmost app → keycode for current layout → post ⌘V. Explicit UX for: no Accessibility grant; activation timeout; macOS secure-input active. **macOS 26/27 pasteboard privacy (accessBehavior) spike in M1**: changeCount + raw types without tripping alerts; read path post-grant; denied/limited UX; PARITY row for Maccy-26/27 behavior. **Hotkey scope (per Maccy wiring, `AppDelegate.disableUnusedGlobalHotkeys` + local `KeyChord` matching)**: only `popup` is a system-global shortcut; pin/delete/togglePreview are local in-popup key bindings (M2 test: popup closed ⇒ ⌥P types π in TextEdit). Hold-to-cycle popup hotkey behavior (hold → `.cycle` highlight advance, modifier release → select) is a PARITY row (M2). **Signing & hardened runtime**: MyGo's build pipeline signs → DMG (+notarize) → update archive in one pass, and already emits `--options runtime --timestamp` whenever a real identity is set (`production` signing). ⇒ **No post-build re-sign** (it would stale the DMG/notarization/update archive). Instead: set `macos.signingIdentity` (self-signed dev cert from M1) in `mygo.json`; CLI helper placed in `resources/darwin-<arch>/` before build so nested-code signing covers it; post-sign reserved for ad-hoc **dev** runs only (`-skip-dmg`). M1 gate: `codesign -dv` on the app **extracted from the DMG and from the update archive** shows `flags=…runtime`. M1 spike: hardened runtime + library validation under the dev identity loads the bundled `mygo-sqlite3` dylib (LV = same-Team-ID/Apple; self-signed typically has no Team ID ⇒ if load fails: Developer ID/Team ID decision escalates to PRE-M1, or LV loss = documented deviation). Injection-refusal check (unsigned dylib refused) on the same spike. **App posture: non-sandboxed** (Maccy-like); single data dir `~/Library/Application Support/com.l92labs.myclip/` via `SetPath(PathUserData, …)` (0700, fchmod-tightened if pre-existing); entitlements: none beyond defaults. **Updater gates need an `updates` config**: M1 packaged build sets `updates` (feed URL placeholder + public key; private key only via `MYGO_UPDATER_PRIVATE_KEY` env, never committed) and asserts `Updater.Enabled()==true` as a test precondition (app run from a writable copy, e.g. `~/Applications`, never the DMG mount); without that config `Enabled()` is false and both the pre-seed test and nettop-past-10s pass vacuously. If updates config proves infeasible at M1, the updater + update-archive gates are marked **explicitly N/A at M1 → owned by M5** (never silently skipped). Update-archive codesign check itself is **M5** (M1 = DMG-extracted app only — MyGo writes no update archive without feed + ed25519 key).
7. **Automation surface (replaces naive URL scheme)**: local CLI (`myclip select|get|delete|clear|ignore-events|ignore-next`) over a unix socket at `~/Library/Application Support/com.l92labs.myclip/run/myclip.sock` (fixed path; `sun_path` 104-byte check), socket file 0600 in 0700 dir (fchmod-tightened if pre-existing), **disabled by default = listener not bound** (opt-in setting). **Honest threat model**: the SecCode/designated-requirement peer check proves the client *is* the signed `myclip` CLI — but any same-user process can spawn that CLI, so once the socket is enabled, any same-user process can read and clear history. (The DB is same-UID-readable anyway ⇒ SecCode is a tamper tripwire, not a confidentiality boundary.) Residual accepted and surfaced: `get` and destructive verbs sit behind their own opt-ins, separate from "socket enabled"; `clear`/`delete` require in-app confirmation even with `--yes` (no silent destructive automation); `select` from the CLI never pastes (paste-back stays a UI action — prevents confused-deputy ⌘V under MyClip's Accessibility grant). D1 sign-off text + settings UI show this residual. M1 deliverable includes the minimal socket+CLI skeleton (bind/unbind, ignore-events verb) so these tests are real — **and the M1 gate checklist explicitly includes**: socket bind/unbind + `ignore-events` verb, foreign-signed/unsigned peer rejected (tripwire; peer identity via `LOCAL_PEERTOKEN` audit token → `kSecGuestAttributeAudit`, not pid — pid-reuse/exec-after-connect race), socket path/mode asserted, listener absent when disabled, exec-after-connect client test. **Hold-to-cycle popup hotkey: M1 spike, single exclusive owner** — the popup chord is owned ONLY by MyClip's purego Carbon `RegisterEventHotKey` shim (MyGo `GlobalShortcut` is never registered for it — grep gate; MyGo's Carbon handler ignores `EventHotKeyID.Signature` and would swallow foreign IDs). Spike pass criterion: **modifier release detected while the popup is open** (`flagsChanged` local monitor or `CGEventSourceFlagsState` poll — Carbon `kEventHotKeyReleased` fires on key-up of C, not modifier release, and alone is insufficient); handler checks Signature and returns `eventNotHandledErr` for foreign IDs. Failure ⇒ deviation D11 (user sign-off); M4 recorder on the same path. Shortcuts integration via "Run Shell Script". Deviation **D1 (restated)** vs App Intents: no native intents framework; residual gap = Shortcuts shows a shell step instead of a native intent (Select/Get/Clear/Delete semantics preserved, with the same-user trust residual above).
