# MyClip — Implementation Plan (v3)

Lightweight, open-source, 100%-local clipboard manager for macOS. **Parity contract: Maccy 2.7.1 @ `eb03eba` — `PARITY.md` is the authoritative inventory.** Stack: Go + [MyGo](https://mygo.egoist.dev) v0.5.5 (pure Go, no cgo, native GPU UI, tray, global shortcuts, clipboard APIs, SQLite plugin, updater).

Repo: `L92-Labs/myclip` (private now; public later). MIT + `NOTICE.md` (Maccy notice reproduced verbatim @ 2.7.1). Bundle ID `com.l92labs.myclip` (locked; TCC keys off code-signing identity ⇒ stable signing identity required from M1). Go module `github.com/L92-Labs/myclip`.

Revisions: v1 → v2 (round-1 review, 44 findings) → v3 (round-2 review, 34 findings). Full per-finding ledger: `LEDGER.md`.

## Non-negotiable constraints

- N1: No cloud, no telemetry, no unsolicited network — production included. SQLite: MyGo gates its native-lib download behind a runtime `IsPackaged()` check (NOT compile-time); ⇒ N1 evidence (nettop zero-outbound) runs on a **packaged `.app`** from `mygo build` (library bundled), never on dev builds; system `libsqlite3.dylib` is NOT a fallback (missing MyGo shim symbols); `MYGO_SQLITE_LIBRARY` is dev-only and asserted unset in release builds. Updater: constructed only as `updater.New(Options{DisableAutomaticChecks: true, …})`; bare `updater.Plugin` forbidden (grep); `SetAutomaticChecks`/`SetAutomaticDownloads` callable only from the settings toggle handler; CI test asserts a fresh state file yields `AutomaticChecks()==false` (persisted state would otherwise override the constructor).
- N2: Behavioral parity with Maccy 2.7.1 per `PARITY.md`; every row maps to a milestone or an approved deviation (D1–D10 in PARITY §6; new deviations require user sign-off before implementation). Gaps found later = findings; never silent drops.
- N3: Open source (MIT); Maccy notice verbatim; THIRD_PARTY_NOTICES generated at M5.
- N4: Measurable per milestone evidence gate: binary size, idle RSS, idle CPU% over ≥5 min — "no busy-wait; envelope comparable to Maccy side-by-side in Activity Monitor."
- N5: Review gates per `feature-review-loop` skill; every gate reviewer gets a full fresh-defect pass on the final revision (gate minimums are never reduced by routing). User routing preference: Cursor Agent Auto does the heavy/deep passes; Claude/ChatGPT at skill minimum. cgo is a hard non-goal; any capability impossible via purego becomes an explicit plan decision, never silent.
- N6: Security: ignore test = **any** banned/concealed/transient UTI present in the **full raw pasteboard type set** ⇒ ignore before any data read (never strip-then-check). Secrets never enter the DB.

## Architecture

1. **Purego darwin shim layer** (`internal/darwin`): `changeCount`; raw UTI enumeration (`NSPasteboard.types`, incl. MIME-less types); `frontmostApplication` bundle ID; keycode-from-layout (TIS/UCKeyTranslate; QWERTY force when layout name ends `⌘`); CGEvent posting; tray `NSEvent.modifierFlags` probe inside `OnClick` (spike; fallback = menu items, then PARITY row demotion = deviation). Pasteboard access behind an interface with a read-counting fake for Linux tests + named-`NSPasteboard` darwin test (N6 test seam).
2. **Item model**: one history item, N representations (raw UTI + bytes), source bundle ID, firstCopiedAt/lastCopiedAt, numberOfCopies, pin, title override. Dedup/equality per Maccy's supersede rule — exact excluded/transient-type list ported from `HistoryItem` @ `eb03eba` as an M1 pre-task (asserted in PARITY §1, not summarized). **Own-write handling: NOT skipped — full `History.add` merge matrix: match by representation set ⇒ update lastCopiedAt + numberOfCopies + position; preserve firstCopiedAt, pin, title; application/source rules per Maccy's `.fromMaccy` path.** M1 tests: copy-back bumps count; pinned-item copy-back stays pinned; no dup row. Marker UTI `com.l92labs.myclip.own-write` identifies origin.
3. **Capture pipeline (Maccy-ported rules, each with M1 test)**: early-exit on `ignoreEvents` / `ignoreOnlyNextEvent` (before any type inspection); then ignore chain on the **full raw type set**: ignore if disjoint from `enabledPasteboardTypes`, or if ANY intersection with (always-ignore trio ∪ `ignoredPasteboardTypes` ∪ addable `com.apple.is-remote-clipboard`); then source app (ignoredApps / allowlist) → regex on text. Content rules: merge multiple `pasteboardItems` into one record; skip empty `string` unless RTF/HTML present; strip `dyn.*` and `com.microsoft.ole.source.*`; drop Word ObjectLink/Link-Source sets.
4. **Storage**: SQLite. File pre-created `O_CREAT|O_EXCL` mode 0600 in 0700 dir **before** `sqlite.Open` (MyGo creates 0644 by default); sidecar (`-journal`/`-wal`/`-shm`) modes asserted in M1 test. **Journal mode pinned** (`DELETE`, or WAL + `wal_checkpoint(TRUNCATE)` + `VACUUM` on clear-all); secure_delete pragma per-connection; forensics test greps DB dir (sidecars incl.) for sentinel after clear. Size caps + total budget = **deviation D6** (user sign-off; D1/D5/D6 block M1 until approved). Enabled-types default set verified against `Defaults.Keys+Names.swift` as M1 pre-task.
5. **App shell**: accessory app, no Dock icon. **Non-activating popup spike moved to M1** (key window without app activation, text input works, Esc + focus-loss close) — paste-back spike runs from that real window type, so the M1 focus model is validated on the final surface.
6. **Paste-back**: CGEvent-only (no osascript — avoids a second Automation TCC prompt). Sequence: hide popup → bounded activate/wait on captured (pre-popup) frontmost app → keycode for current layout → post ⌘V. Explicit UX for: no Accessibility grant; activation timeout; macOS secure-input active. **macOS 26/27 pasteboard privacy (accessBehavior) spike in M1**: changeCount + raw types without tripping alerts; read path post-grant; denied/limited UX; PARITY row for Maccy-26/27 behavior. **Hotkey scope (per Maccy wiring)**: only `popup` is a system-global shortcut; pin/delete/togglePreview are local in-popup key bindings (Maccy matches them inside the popup's key handler — wiring re-verified at `eb03eba` as M1 pre-task; M2 test: popup closed ⇒ ⌥P types π in TextEdit). **Hardened runtime + library validation ON from M1**, including self-signed dev builds (an Accessibility-trusted process must refuse injected code — `DYLD_INSERT_LIBRARIES`, swapped dylibs, `MYGO_SQLITE_LIBRARY` in release); M1 spike asserts an injected unsigned dylib is refused; M5 "unsigned" fallback = ad-hoc signed + hardened runtime, else documented risk.
7. **Automation surface (replaces naive URL scheme)**: local CLI (`myclip select|get|delete|clear|ignore-events|ignore-next`) over a unix socket, **disabled by default** (opt-in setting). Threat model (peer-UID alone is insufficient — any same-user process passes): peer verified via **audit token → SecCode → designated requirement of the bundled `myclip` CLI** (code-signing check); M1 test: foreign-signed/unsigned peer rejected. `select` from the CLI never pastes (paste-back stays a UI action; CLI paste = separate verb, explicit opt-in, never default) — prevents confused-deputy injection under MyClip's Accessibility grant and bypass of macOS 26/27 pasteboard privacy via `get`. Destructive verbs (`delete`/`clear`): interactive CLI → in-app confirmation; automation (`--yes`) only while the socket setting is enabled. Shortcuts integration via "Run Shell Script". Deviation **D1 (restated)** vs App Intents: no native intents framework; residual gap = Shortcuts shows a shell step instead of a native intent (Select/Get/Clear/Delete semantics preserved).
