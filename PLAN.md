# MyClip — Implementation Plan (v5)

Lightweight, open-source, 100%-local clipboard manager for macOS. **Parity contract: Maccy 2.7.1 @ `eb03eba` — `PARITY.md` is the authoritative inventory.** Stack: Go + [MyGo](https://mygo.egoist.dev) v0.5.5 (pure Go, no cgo, native GPU UI, tray, global shortcuts, clipboard APIs, SQLite plugin, updater).

Repo: `L92-Labs/myclip` (private now; public later). MIT + `NOTICE.md` (Maccy notice reproduced verbatim @ 2.7.1). Bundle ID `com.l92labs.myclip` (locked; TCC keys off code-signing identity ⇒ stable signing identity required from M1). Go module `github.com/L92-Labs/myclip`.

Revisions: v1 →(R1: 44 findings)→ v2 →(R2: 34)→ v3 →(R3: 18 + GLM run incomplete)→ v4 →(R4: Cursor 5 / GLM 9 / Opus 6)→ v5. Full per-finding ledger: `LEDGER.md`.

## Non-negotiable constraints

- N1: No cloud, no telemetry, no unsolicited network — production included. SQLite: MyGo gates its native-lib download behind a runtime `IsPackaged()` check (NOT compile-time); ⇒ N1 evidence (nettop zero-outbound) runs on a **packaged `.app`** from `mygo build` (library bundled), never on dev builds; system `libsqlite3.dylib` is NOT a fallback (missing MyGo shim symbols); `MYGO_SQLITE_LIBRARY` is dev-only and asserted unset in release builds. Updater: constructed only as `updater.New(Options{DisableAutomaticChecks: true, …})`; bare `updater.Plugin` forbidden (grep); `SetAutomaticChecks` called with `false` by MyClip on every launch before `WhenReady` (MyClip owns the toggle state — persisted plugin state can otherwise override the constructor; the plugin's own update-window checkbox may write `AutomaticDownloads`); M1 spike probes the MyGo updater API surface (getter, state-file path/format per OS) and, if a plain fresh-state test is infeasible, the gate falls back to options introspection + nettop zero-egress across first-launch idle.
- N2: Behavioral parity with Maccy 2.7.1 per `PARITY.md`; every row maps to a milestone or an approved deviation (D1–D10 in PARITY §6; new deviations require user sign-off before implementation). Gaps found later = findings; never silent drops.
- N3: Open source (MIT); Maccy notice verbatim; THIRD_PARTY_NOTICES generated at M5.
- N4: Measurable per milestone evidence gate: binary size, idle RSS, idle CPU% over ≥5 min — "no busy-wait; envelope comparable to Maccy side-by-side in Activity Monitor."
- N5: Review gates per `feature-review-loop` skill; every gate reviewer gets a full fresh-defect pass on the final revision (gate minimums are never reduced by routing). User routing preference: Cursor Agent Auto does the heavy/deep passes; Claude/ChatGPT at skill minimum. cgo is a hard non-goal; any capability impossible via purego becomes an explicit plan decision, never silent.
- N6: Security: ignore test = **any** banned/concealed/transient UTI present in the **full raw pasteboard type set** ⇒ ignore before any data read (never strip-then-check). Secrets never enter the DB.

## Architecture

1. **Purego darwin shim layer** (`internal/darwin`): `changeCount`; raw UTI enumeration (`NSPasteboard.types`, incl. MIME-less types); `frontmostApplication` bundle ID; keycode-from-layout (TIS/UCKeyTranslate; QWERTY force when layout name ends `⌘`); CGEvent posting; tray `NSEvent.modifierFlags` probe inside `OnClick` (spike; fallback = menu items, then PARITY row demotion = deviation). Pasteboard access behind an interface with a read-counting fake for Linux tests + named-`NSPasteboard` darwin test (N6 test seam).
2. **Item model**: one history item, N representations (raw UTI + bytes), source bundle ID, firstCopiedAt/lastCopiedAt, numberOfCopies, pin, title override. Dedup/equality per Maccy's supersede rule — exact excluded/transient-type list ported from `HistoryItem` @ `eb03eba` as an M1 pre-task (asserted in PARITY §1, not summarized). **Own-write handling: NOT skipped — full `History.add` merge matrix: match by representation set ⇒ update lastCopiedAt + numberOfCopies + position; preserve firstCopiedAt, pin, title; application/source rules per Maccy's `.fromMaccy` path.** M1 tests: copy-back bumps count; pinned-item copy-back stays pinned; no dup row; firstCopiedAt and title-override preserved. Marker UTI `com.l92labs.myclip.own-write` identifies origin.
3. **Capture pipeline (Maccy-ported rules, each with M1 test)**: early-exit on `ignoreEvents` / `ignoreOnlyNextEvent` (before any type inspection); then ignore chain on the **full raw type set**: ignore if disjoint from `enabledPasteboardTypes`, or if ANY intersection with (always-ignore trio ∪ `ignoredPasteboardTypes` ∪ addable `com.apple.is-remote-clipboard`); then source app (ignoredApps / allowlist) → regex on text. Content rules: merge multiple `pasteboardItems` into one record; skip empty `string` unless RTF/HTML present; strip `dyn.*` and `com.microsoft.ole.source.*`; drop Word ObjectLink/Link-Source sets.
4. **Storage**: SQLite. File pre-created `O_CREAT|O_EXCL` mode 0600 in 0700 dir **before** `sqlite.Open` (MyGo creates 0644 by default); on pre-existing file (`EEXIST`, e.g. earlier dev build): `fstat` + `fchmod` to 0600 (dir 0700) or refuse startup; sidecar (`-journal`/`-wal`/`-shm`) modes asserted in M1 test. **Journal mode pinned** (`DELETE`, or WAL + `wal_checkpoint(TRUNCATE)` + `VACUUM` on clear-all); secure_delete pragma per-connection; forensics test greps DB dir (sidecars incl.) for sentinel after clear. Size caps + total budget = **deviation D6** (user sign-off; D1/D5/D6 block M1 until approved). Enabled-types default set verified against `Defaults.Keys+Names.swift` as M1 pre-task.
5. **App shell**: accessory app, no Dock icon. **Non-activating popup spike moved to M1** (key window without app activation, text input works, Esc + focus-loss close) — paste-back spike runs from that real window type, so the M1 focus model is validated on the final surface.
6. **Paste-back**: CGEvent-only (no osascript — avoids a second Automation TCC prompt). Sequence: hide popup → bounded activate/wait on captured (pre-popup) frontmost app → keycode for current layout → post ⌘V. Explicit UX for: no Accessibility grant; activation timeout; macOS secure-input active. **macOS 26/27 pasteboard privacy (accessBehavior) spike in M1**: changeCount + raw types without tripping alerts; read path post-grant; denied/limited UX; PARITY row for Maccy-26/27 behavior. **Hotkey scope (per Maccy wiring, `AppDelegate.disableUnusedGlobalHotkeys` + local `KeyChord` matching)**: only `popup` is a system-global shortcut; pin/delete/togglePreview are local in-popup key bindings (M2 test: popup closed ⇒ ⌥P types π in TextEdit). Hold-to-cycle popup hotkey behavior (hold → `.cycle` highlight advance, modifier release → select) is a PARITY row (M2). **Hardened runtime**: MyGo's toolchain emits `--options runtime` only for production builds with a real identity (`cmd/mygo/bundle.go` gates on `production && identity != "-"`) ⇒ a **post-`mygo build` re-sign step** (bundled sqlite dylib + CLI helper first, then the app; `--options runtime`; never `--deep`) produces hardened-runtime builds from M1 onward. M1 spike: packaged app under hardened runtime + library validation, signed with the chosen dev identity, loads the bundled `mygo-sqlite3` dylib (LV allows same-Team-ID or Apple dylibs — self-signed/ad-hoc has no Team ID; if the load fails, the Developer ID/Team ID decision moves to PRE-M1 or LV loss becomes a documented deviation). Injection-refusal check (unsigned dylib refused) on the same spike.
7. **Automation surface (replaces naive URL scheme)**: local CLI (`myclip select|get|delete|clear|ignore-events|ignore-next`) over a unix socket at `<app-container>/myclip.sock`, socket file 0600 in 0700 dir, **disabled by default = listener not bound** (opt-in setting). **Honest threat model**: the SecCode/designated-requirement peer check proves the client *is* the signed `myclip` CLI — but any same-user process can spawn that CLI, so once the socket is enabled, any same-user process can read and clear history. (The DB is same-UID-readable anyway ⇒ SecCode is a tamper tripwire, not a confidentiality boundary.) Residual accepted and surfaced: `get` and destructive verbs sit behind their own opt-ins, separate from "socket enabled"; `clear`/`delete` require in-app confirmation even with `--yes` (no silent destructive automation); `select` from the CLI never pastes (paste-back stays a UI action — prevents confused-deputy ⌘V under MyClip's Accessibility grant). D1 sign-off text + settings UI show this residual. M1 tests: foreign-signed/unsigned peer rejected (tripwire), socket path/mode asserted, listener absent when disabled. Shortcuts integration via "Run Shell Script". Deviation **D1 (restated)** vs App Intents: no native intents framework; residual gap = Shortcuts shows a shell step instead of a native intent (Select/Get/Clear/Delete semantics preserved, with the same-user trust residual above).
