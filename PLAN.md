## Architecture

1. **Purego darwin shim layer** (`internal/darwin`): `changeCount`; raw UTI enumeration = `NSPasteboard.types` ∪ ⋃ `pasteboardItems[i].types` (both, incl. MIME-less types; parity ignore surface = `pasteboard.types` superset — see N6 rationale); `frontmostApplication` bundle ID; keycode-from-layout (TIS/UCKeyTranslate; QWERTY force when layout name ends `⌘`); CGEvent posting; tray `NSEvent.modifierFlags` probe inside `OnClick` (spike; fallback = menu items, then PARITY row demotion = deviation). Pasteboard access behind an interface with a read-counting fake for Linux tests + named-`NSPasteboard` darwin test (N6 test seam).
2. **Item model**: one history item, N representations (raw UTI + bytes), source bundle ID, firstCopiedAt/lastCopiedAt, numberOfCopies, pin, title override. Dedup/equality per Maccy's supersede rule — exact excluded/transient-type list ported from `HistoryItem` @ `eb03eba` as an M1 pre-task (asserted in PARITY §1, not summarized). **Own-write handling: NOT skipped — full `History.add` merge matrix: match by representation set ⇒ update lastCopiedAt + numberOfCopies + position; preserve firstCopiedAt, pin, title; application/source rules per Maccy's `.fromMaccy` path.** Marker UTI `com.l92labs.myclip.own-write` is **metadata only**: checked for origin, never stored as a representation, never restored from DB reps (it IS placed on the general pasteboard on MyClip's own writes — that is how own-writes are detected, same model as `.fromMaccy`, so other pasteboard readers can see it), excluded from the equality set (occupies the `.fromMaccy` slot in the ported excluded-types list). The marker is forgeable by any writer, so it gates nothing: every capture — marker present or not — runs the full ignore chain (§3) and the N6 union check before any merge decision; the marker only selects merge-vs-new-row attribution. M1 test `forged-marker-concealed`: foreign write carrying `com.l92labs.myclip.own-write` + a Concealed type ⇒ zero reads, zero rows. M1 tests: copy-back bumps count; pinned stays pinned; no dup row; firstCopiedAt and title-override preserved; no marker rep in DB after copy-back; equality excludes marker.
3. **Capture pipeline (Maccy-ported rules, each with M1 test)**: early-exit **only** on `ignoreEvents` (on that exit, if `ignoreOnlyNextEvent` is set, both flags are cleared — skip-exactly-one semantics). Tray coupling: **M1 pre-task quotes the exact `performStatusItemClick` body @ `eb03eba` into PARITY §1** (the ⌥/⌥⇧ flag assignments must be ported verbatim — as-written approximations are forbidden; the `ignore-next` CLI verb (D5) sets both flags with the same effect as the tray path). M1 tests: pause-sticky, from-unpaused ⌥⇧click → next copy skipped → the copy after it captured, no OR-false-positive. Ignore chain on the **full raw type set**: ignore if disjoint from `enabledPasteboardTypes`, or if ANY intersection with (always-ignore trio ∪ user's `ignoredPasteboardTypes`); `com.apple.is-remote-clipboard` enters the set **only via user setting** (verified @2.7.1: `Defaults.Keys+Names.swift:39-46` default = exactly 5 entries, no `com.apple.is-remote-clipboard`) — default builds must capture Universal Clipboard copies. Then source app (ignoredApps / allowlist) → regex on text. Content rules: merge multiple `pasteboardItems` into one record; skip empty `string` unless RTF/HTML present; strip `dyn.*` and `com.microsoft.ole.source.*`; drop Word ObjectLink/Link-Source sets. **PasteStack/multi-select: not ported — disabled dead code in 2.7.1** (`AppState.multiSelectionEnabled = false` ⇒ `startPasteStack` guard unreachable; rejected with evidence in LEDGER; revisit if upstream enables it).
4. **Storage**: SQLite. File pre-created `O_CREAT|O_EXCL` mode 0600 in 0700 dir **before** `sqlite.Open` (MyGo creates 0644 by default); on pre-existing file (`EEXIST`, e.g. earlier dev build): `fstat` + `fchmod` to 0600 (dir 0700) or refuse startup; sidecar (`-journal`/`-wal`/`-shm`) modes asserted in M1 test. **Journal mode pinned** (`DELETE`, or WAL + `wal_checkpoint(TRUNCATE)` + `VACUUM` on clear-all); secure_delete pragma per-connection; forensics test greps DB dir (sidecars incl.) for sentinel after clear. Size caps + total budget = **deviation D6** (user sign-off; D1/D5/D6 block M1 until approved). Enabled-types default set verified against `Defaults.Keys+Names.swift` as M1 pre-task.
5. **App shell**: accessory app, no Dock icon. **Non-activating popup spike moved to M1** (key window without app activation, text input works, Esc + focus-loss close) — paste-back spike runs from that real window type, so the M1 focus model is validated on the final surface.
6. **Paste-back**: CGEvent-only (no osascript — avoids a second Automation TCC prompt). Sequence: hide popup → bounded activate/wait on captured (pre-popup) frontmost app → keycode for current layout → post ⌘V. Explicit UX for: no Accessibility grant; activation timeout; macOS secure-input active. **macOS 26/27 pasteboard privacy (accessBehavior) spike in M1**: changeCount + raw types without tripping alerts; read path post-grant; denied/limited UX; PARITY row for Maccy-26/27 behavior. **Hotkey scope (per Maccy wiring, `AppDelegate.disableUnusedGlobalHotkeys` + local `KeyChord` matching)**: only `popup` is a system-global shortcut; pin/delete/togglePreview are local in-popup key bindings (M2 test: popup closed ⇒ ⌥P types π in TextEdit). Hold-to-cycle popup hotkey behavior (hold → `.cycle` highlight advance, modifier release → select) is a PARITY row (M2). **Signing & hardened runtime**: MyGo's build pipeline signs → DMG (+notarize) → update archive in one pass, and already emits `--options runtime --timestamp` whenever a real identity is set (`production` signing). ⇒ **No post-build re-sign** (it would stale the DMG/notarization/update archive). Instead: set `macos.signingIdentity` (self-signed dev cert from M1) in `mygo.json`; CLI helper placed in `resources/darwin-<arch>/` before build so nested-code signing covers it; post-sign reserved for ad-hoc **dev** runs only (`-skip-dmg`). M1 gate: `codesign -dv` on the app **extracted from the DMG and from the update archive** shows `flags=…runtime`. M1 spike: hardened runtime + library validation under the dev identity loads the bundled `mygo-sqlite3` dylib (LV = same-Team-ID/Apple; self-signed typically has no Team ID ⇒ if load fails: Developer ID/Team ID decision escalates to PRE-M1.
